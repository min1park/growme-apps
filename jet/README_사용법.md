# 저널엔트리테스트(JET) 자동화 — v2.0 범용

브라우저에서 동작하는 범용 JET/원장가공 도구. 모든 처리는 브라우저 내에서만 수행되며 데이터는 서버로 전송되지 않습니다. `index.html`을 브라우저로 열면 됩니다.

## 처리 흐름 (8단계)

1. **분개장 업로드** — 회사 총계정원장(GL) xlsx/csv
2. **필드 매핑** — 회사 컬럼을 표준필드(회계일/전표번호/계정과목/차변/대변/…)에 매핑. 원본 전 컬럼은 `_raw`로 자동 보존
3. **CoA 계정체계 매핑 (선택)** — 계정과목↔코드↔계층 매핑표 업로드 시 CoA 계층 자동 부착. **없어도 진행 가능**
4. **기초잔액 업로드 (선택)** — B/S 계정 기초잔액. 있으면 `기초+차변-대변=기말` 완성. 없으면 당기증감만
5. **데이터 검증** — 차대일치 등 완전성 체크 + 요약 메트릭
6. **산출물 확인** — 계정별 증감표 / 월별 증감표 / 시각화 / 가공원장 미리보기
7. **이상분개 탐지 (JET)** — 주말·라운드넘버·적요없음·기표자=승인자·승인자없음·결산일전후·대금액·비정상계정조합·역분개·특정사용자
8. **리포트 다운로드** — 개별(가공원장/증감표/JET/검증) 또는 통합 1파일

## CoA 매핑표 형식 (범용)

어떤 컬럼명이든 3단계에서 지정하면 됩니다. 최소 **계정과목명** 1개만 있으면 동작.

| 지정 필드 | 설명 | 필수 |
|---|---|---|
| 계정과목코드 | GL 계정코드 | 선택 |
| 계정과목명 | 매칭 키 | **필수** |
| 대구분 | 자산/부채/자본/수익/비용 | 선택 |
| 중구분 / 공시단위CoA | 계층 | 선택 |
| 연결CoA코드 / 연결CoA | 공시용 CoA | 선택 |

**대분류 자동판정**: 대구분 컬럼이 없어도 ①연결CoA코드 첫 글자(A자산 L부채 E·Q자본 R수익 C비용) ②계정과목코드 첫 자리(1자산 2부채 3자본 4수익 5·9비용 6영업외)로 보정.

**계정과목명 매칭**: 완전일치 → 공백무시 → 괄호접미사 제거(예: `여비교통비(제조)` → `여비교통비`) 순으로 자동 매칭.

## 기초잔액 형식

계정과목코드 / 계정과목명 / 증감(잔액; 자산+, 부채·자본−) 3개 컬럼 지정.
전기말 잔액을 당기초로 승계할 때 사용. 손익계정은 기초 0.

## 다른 회사 적용

이 도구는 특정 회사 컬럼명에 의존하지 않습니다. 원장·CoA매핑표·기초잔액을 각 회사 양식대로 업로드하고 3·4단계에서 컬럼만 지정하면 그대로 동작합니다.
